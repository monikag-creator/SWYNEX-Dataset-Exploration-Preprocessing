# SWYNEX-Dataset-Exploration-Preprocessing

Task 1 submission for the SWYNEX Technologies ML Internship (Data & AI).

## Overview
Explored the PlantVillage dataset (38 classes, ~54,000 leaf images) 
covering healthy and diseased plant leaves across 14 crop species.

## Steps Covered
- Downloaded dataset using kagglehub
- Explored folder structure and class distribution
- Visualized number of images per class
- Previewed sample leaf images from different disease categories

[PlantVillage on Kaggle](https://www.kaggle.com/datasets/mohitsingh1804/plantvillage)
